## ADDED Requirements

### Requirement: Edit AI-generated specialties and value points
The system SHALL allow the user to edit the AI-generated specialties (title and description of each) and value-proposition points without editing code.

#### Scenario: Edit a specialty
- **WHEN** the user changes a specialty's title or description in the editor
- **THEN** the change is saved to the site configuration and reflected in the preview

#### Scenario: Edit a value point
- **WHEN** the user changes a value-proposition point
- **THEN** the change is saved and reflected in the preview
